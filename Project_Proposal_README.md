## Project Title
**Local Market Price Tracker for Agricultural Commodities in Uganda**

## Description
This project aims to develop a Python-based application that helps farmers and traders record, store, and visualize daily market prices for agricultural products. It uses object-oriented programming principles and Python libraries to create a simple, offline-capable tool.

## Features
- Record daily prices for multiple products and markets
- Store data locally (CSV, Excel, SQLite)
- Visualize price trends over time
- Compare prices across markets
- Simple CLI or optional GUI using Tkinter

## Technologies
- Python 3.x
- pandas
- matplotlib
- datetime
- openpyxl
- sqlite3 (optional)
- Tkinter (optional GUI)
